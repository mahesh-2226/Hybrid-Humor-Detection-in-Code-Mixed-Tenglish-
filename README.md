# Hybrid-Humor-Detection-in-Code-Mixed-Tenglish-
Humor Detection in Tenglish -- A hybrid NLP approach for detecting humor in Romanized Telugu-English text using transformer models and rule-based heuristics. Evaluates models including MuRIL, mBERT, XLM-R, IndicBERT, and others, with cross-dataset testing on 10K balanced samples.
